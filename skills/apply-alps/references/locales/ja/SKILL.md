# ALPS適用プロセス

## 目的

本プロセスは、適用可能なALPS表現を選択して読み込み、適用状況に必要なプロセスを解決し、プロセススキルを単独または組み合わせて適用することにより、意図した成果を達成する。

## 成果

本プロセスの成功によって、次の状態が成立している。

- a) 適用状況のニーズ、条件およびリスクが識別されている。
- b) 必要に応じてプロセスモデル、プロセス参照モデル、プロセスビューおよびプロセス表現が選択または読み込まれている。
- c) 選択または読み込んだ表現から候補プロセスが解決されている。
- d) 呼び出すプロセススキルおよび適用形態が、根拠とともに決定されている。
- e) 適用される統制事項、制約、テーラリング判断および意思決定ゲートが、影響対象となる行為が生じる前に識別されている。
- f) プロセスインスタンスが、宣言した適用範囲と適用される統制事項、制約およびテーラリング判断のもとで実行されている。
- g) 適用したプロセスの宣言成果が、観測可能な証拠によって達成されている。
- h) 必要な受け渡しが確立されている。
- i) 複数のプロセスを組み合わせる場合、選択した組み合わせの範囲内で完全性が確立されている。
- j) 適用されるプロセス関係および構造レベル間で整合性が確立されている。

## 活動とタスク

### 表現の選択

1. 適用ニーズ、目標成果、文脈およびリスクを識別する必要がある。
2. 各候補の表現種別を確認する必要がある。
3. プロセスモデル、プロセス参照モデルおよびプロセスビューは、選択に必要な場合だけ読み込む必要がある。
4. 適用される論理参照を解決して、候補プロセスを選択する必要がある。
5. 選択したプロセス、適用形態および選択根拠を記録する必要がある。

### プロセスの呼び出し

1. 選択したプロセス表現およびその開始基準から、呼び出しの準備状況を確認する必要がある。
2. 必要な入力、実行支援要素、統制事項、制約、テーラリング判断および意思決定ゲートを識別する必要がある。
3. 制約によって定めていない順序を仮定せず、宣言した範囲内でプロセスを実行する必要がある。
4. 完了を宣言する前に、完了基準および成果証拠を評価する必要がある。
5. 判断、逸脱、制限および未解決事項を記録する必要がある。

### プロセスの組合せ

1. 組合せの目標成果を識別する必要がある。
2. 提供側出力から受領側入力へのすべての対応を明示する必要がある。
3. 受け渡す各項目の意味、範囲および品質条件を整合させる必要がある。
4. 変更した出力の影響を、受領側入力および適用基準へ伝播する必要がある。
5. 完全性、整合性、受け渡しおよび教訓を、引渡しに向けて評価する必要がある。

| 活動 | 成果 |
| --- | --- |
| 表現の選択 | a)、b)、c)、d) |
| プロセスの呼び出し | d)、e)、f)、g) |
| プロセスの組合せ | g)、h)、i)、j) |

## 入力

- 適用ニーズ、文脈、目標成果およびリスク情報。
- 管理された表現、その状態および適用条件、ならびに適用するテーラリング判断。
- 呼び出し対象として選択したプロセスのプロセス記述および宣言入力。

## 出力

- 選択したプロセス、適用形態および選択根拠。
- プロセス出力、実行証拠および成果証拠、ならびに記録した判断または制限。
- 明示した受け渡し対応、組合せのアセスメントおよび教訓。
- 未充足の表現ニーズまたは変更要求。

## 開始基準

- 適用ニーズおよび重大なリスクを識別できる。
- 候補表現または候補が存在しないことを識別できる。
- 優先して適用する統制事項および重大な制約を判断できる。

## 完了基準

- 表現選択およびプロセス呼び出しの判断が記録されている。
- 呼び出した各プロセスの開始基準、完了基準および成果証拠が評価されている。
- 必要な受け渡し、および該当する場合は組合せの完全性と整合性が評価されている。
- 未解決ニーズ、変更要求、制限および教訓を、適用される受渡し先が利用できる。

## 実行支援要素

- 管理されたALPS表現、ならびに論理参照の解決および選択したプロセスの実行に必要な能力。

## 規範上の根拠

[プロセスフレームワーク](../../../../../spec/process-framework.md)がプロセスの意味を統制し、[ALPS仕様](../../../../../spec/ALPS-SPEC.md)が表現の読込み、プロセスの呼び出し、組合せおよび本プロセスに適用されるALPS固有の要求事項を統制する。

- プロセスの選択または組合せを改善する場合だけ、モデルまたはビューを読み込む。
- 表現の読込みとプロセスの呼び出しを区別する。
