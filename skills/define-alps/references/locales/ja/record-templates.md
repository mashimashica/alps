# ALPS定義プロセス記録テンプレート

表現種別、適用状況およびリスクに応じて必要な記録だけを選択する。不足情報を推測で埋めず、`未確認`、`該当なし`または`保留`として扱う。

## 1. 表現ニーズ記録

```markdown

- 記録ID:
- 状態: 候補 / 選定 / 見送り / 再検討
- ニーズまたは関心事:
- 想定利用者・ステークホルダー:
- 想定利用文脈:
- 既存表現および関連する未充足領域:
- 選定したPFの構成概念: プロセス / プロセスモデル / プロセス参照モデル / プロセスビュー
- 選定根拠:
- 期待便益:
- リスク・制約:
- 必要な詳細度:
- 未解決事項:
```

## 2. 表現の追跡可能性

表現種別と適用状況に合う安定した参照方法を用いる。プロセスでは成果、活動、タスク、入力と出力および証拠を追跡する。モデルおよびビューでは、必要に応じて表現対象または出典プロセス、正規のスキル参照、関係および来歴を追跡する。プロセスビューが出典プロセスの活動またはタスクを参照する場合、その出典との関係を識別できるだけの来歴と追跡可能性を維持する。

| 出典または要素 | 関係 | 対象または関連要素 | 証拠または参照 | 状態 |
|---|---|---|---|---|
| | | | | 未評価 / 適合 / 欠陥 / 対象外 |

確認観点:

- 表現対象となるPFの構成概念と、宣言または既定の表現種別が一致している。
- 必須の正規のスキル参照が解決される。
- プロセス参照モデルでは、参照する各プロセスの名称、目的および成果が、正本となるプロセス記述と一致している。
- プロセスビューでは、参照する出典要素の来歴と追跡可能性を維持し、ビュー内の記述と出典プロセスの変更を区別している。
- 提供側の出力から受領側の入力への対応をすべて明示し、受け渡す意味および範囲を整合させている。
