# ALPS管理プロセス記録補助

以下のブロックは、ALPS表現およびその適用の管理を記録するための任意の補助である。適用状況とリスクに照らして必要なものだけを選択する。ALPS管理プロセスの基準版と、管理対象となる表現の基準版は分けて記録する。

| 項目 | 内容 |

| 表現名・参照 | |
| 表現種別: プロセス / プロセスモデル / プロセス参照モデル / プロセスビュー | |
| 管理対象の基準版 | |
| 現在の管理上の取扱い | |
| 目的または関心事・適用範囲 | |
| 発見・読込み情報 | |
| 必須参照・解決状態 | |
| 検証証拠 | |
| 依存先、参照プロセスおよび利用者 | |
| 適用統制事項・制約 | |
| 該当する場合のテーラリング条件 | |
| 関連変更・影響を受ける表現 | |
| レビューまたは再検証の要否・結果 | |
| 廃止・保持・復旧条件 | |

## 参照整合性・変更記録

```markdown
# 参照整合性・変更記録

- 対象表現・基準版:
- 表現種別:
- 提案または観察された変更:
- 影響を受ける正本となる意味上の中核:
- 影響を受ける参照元・参照先表現:
- 影響を受ける正規のスキル参照:
- 互換性または解決への影響:
- 必要な再定義・再検証:
- 周知・移行への影響:
- 決定・根拠:
- 証拠・未解決リスク:
```

表現が正本として持つ意味を変更する場合は、ALPS定義プロセスへ引き渡して再定義・検証する。管理上の判断によって、正本となる表現を暗黙に再定義しない。

## テーラリング決定

特定の適用状況に合わせてプロセスをテーラリングする場合、または適用するプロセスモデルの選択を調整する場合に用いる。プロセスビューは判断材料になり得るが、ビュー固有または変更された活動やタスクは、それ自体ではテーラリングを成立させない。出典プロセスが正本として持つ意味を変更する場合は、ALPS定義プロセスへプロセス再定義として引き渡す。

```markdown
# テーラリング決定

- 対象プロセスまたは適用するモデル、および管理されたベースライン:
- 適用状況・範囲:
- 評価した候補プロセスまたはライフサイクルモデル、基準および結果:
- 変更分類: 適用状況固有のテーラリング / 正本の再定義
- 影響要素:
- 出典記述または関係:
- テーラリング結果:
- 変更した場合のテーラリング前後のプロセス名称:
- 目的・成果との名称整合性、および出典プロセスへの追跡可能性:
- 適用統制事項・制約:
- リスク・証拠:
- 影響当事者・取得した入力:
- 決定・根拠:
- 適用範囲に残るすべての成果、および活動またはタスクに「〜する必要がある」または「〜してはならない」で示された適用範囲内のすべての要求事項:
- 入力、出力、受け渡しおよび参照への影響:
- 監視・アセスメント方法:
- 見直し条件:
- 適合主張がある場合はその内容:
```

## 参照プロセス適合主張

ALPS管理プロセスへの適合を主張しない場合は省略する。主張する場合は、ALPS管理プロセスの基準版、適用範囲、成果適合、タスク適合または双方のどれを基準にするか、結論、証拠および制限を記録する。成果適合を基準とする完全適合の主張では、基準版の全成果を満たす。タスク適合を基準とする完全適合の主張では、活動またはタスクに「〜する必要がある」または「〜してはならない」で示された適用範囲内のすべての要求事項を満たし、推奨、許可および通常の行為は必須としない。テーラリング適合の主張では、テーラリングしたプロセス範囲を識別し、その範囲に残る全成果、および活動またはタスクに同じ規範表現で示された適用範囲内のすべての要求事項の充足を示す。能力は適合とは分けて評価する。
