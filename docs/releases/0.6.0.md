# ALPS 0.6.0

Released: 2026-08-31

ALPS 0.6.0 replaces the former multi-Skill lifecycle, representation, governance, and record system with one focused Agent Skill for designing or redesigning a Process Description. This is an incompatible pre-1.0 MINOR release.

## What Changed

- The package now distributes only [`design-process-description`](../../skills/design-process-description/SKILL.md).
- The root Skill contains the normal design workflow and concrete routing conditions for three optional references: purpose and outcomes, boundary and detail, and inputs, outputs, and conditions.
- English and Japanese counterparts are maintained as ordinary documentation without a synchronization generator or dedicated pipeline.
- Host adapters now expose only Process Description creation, simplification, and evidence-based revision.
- The former specifications, four distributed Skills, repository-development meta Skills, records, templates, generator, diagrams, and specialized tests are removed rather than archived or wrapped.
- Repository validation now checks the single-Skill structure, ordinary Plugin and Host form, relative links, whitespace, icons, localization coverage, and absence of obsolete active-product terms.

## Migration

| Earlier identifier | 0.6.0 direction |
| --- | --- |
| `define-alps` | Use `design-process-description`. |
| `apply-alps` | Apply the target Process Skill directly. |
| `manage-alps` | Use normal Git, repository review, release, and organization policy. |
| `alps-reference-model` | No replacement. |
| `review-alps` | Use ordinary review. |
| `sync-locales` | Use ordinary translation review. |

No alias, redirect, stub, forwarding Skill, compatibility symlink, resolver, or replacement record format is provided. Consumers that require the earlier identifiers or meanings should pin the applicable earlier release or tag.

## Scope

The project and package remain named `alps`; the repository URL, root `skills/` distribution, Agent Plugins manifest, Host adapters, OpenAI interface metadata, branding, licensing, changelog, and Git-based versioning remain. ALPS does not publish a release or create a tag as part of this source change.

See the concise [README](../../README.md) and [versioning policy](../versioning.md).
