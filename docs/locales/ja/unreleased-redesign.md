# 未リリースのプロセス記述再設計

[英語版](../../unreleased-redesign.md)

これは0.5.0の次のMINOR向けの、未リリースの破壊的再設計である。`VERSION`と各manifestの版は変更しない。本説明はリリースの公開やユーザーデータの移行を許可するものではない。

ALPSは、プロセス記述を通じた作業の意味の設計とレビューに焦点を当てる。[フレームワーク](../../../spec/locales/ja/process-framework.md)が意味を定め、[仕様](../../../spec/locales/ja/ALPS-SPEC.md)がAgent Skillへの対応付けを定める。

## 互換性の変更

| 基準状態のファイルにある従来の構成 | 現在の設計 |
| --- | --- |
| `alps-reference-model`、`define-alps`、`apply-alps`、`manage-alps` | 配布するのは`design-process-description`のみ。旧名のaliasは設けない。 |
| 固定の五段階ライフサイクルと三つの必須参照プロセス | ALPSのライフサイクルや管理経路の義務を設けない。 |
| `skill:`参照、Logical Package Scope、Package Binding | 通常のリンクや識別情報を用い、必要な場合は利用環境の版、commit、digestを添える。 |
| `metadata.alps.kind`と型別の呼び出し規則 | 通常の参照資料とプロセス記述を意味上区別する。旧metadataは解釈しない。 |
| ALPS独自のConformance体系と発見情報の定型末尾による主張 | 記述、実行結果、適用される要求を別々に評価する。評価の選択によって必須条件を解除しない。 |
| `process_instance_record.py`、`process-instance-record/1`、記録のBinding | ALPS独自の実行記録形式、CLI、変換器を提供しない。保存と記録は利用環境に委ねる。 |
| 網羅的な記録・Skillテンプレート | 最小の記述テンプレートと少数の具体例。 |

削除した構成に依存する既存の呼び出し、参照、連携は、この再設計を利用する前に意図的なレビューが必要になる。以前の主張は、現在の記述や要求の充足を示さない。ユーザーが作成した既存の記録と記述は変換も削除もしない。互換層や旧実装の代替経路は提供しない。

## 配布とレビュー

Plugin全体ではルートmanifest、Claude/Cursor/Codexアダプター、表示資源、英語正本、日本語対応を維持する。単一Skillの必須参照を利用できるよう、`spec/`を`skills/`と並べて保つ。開発用Skillは分離する。

リポジトリテストと形式検証は、配布物の形式と整合性を評価する。目的と十分な成果、必要な詳細、参照と不確実性、共有情報の関係、文脈条件、日英の同等性は、意味レビューで別に確認する。導入済みパッケージは実際の内容で確認する必要があり、版文字列だけでは未コミットの開発スナップショットを識別できない。
