# ALPS 0.7.0

[英語版](../../../releases/0.7.0.md)

ALPS 0.7.0は、仕事の意味と、それを実現するエージェント作業システムの両方の設計を支援します。

## 設計責務

- [design-process-description](../../../../skills/design-process-description/references/locales/ja/SKILL.md)は、仕事の意味、観察可能な成果、必要な活動とタスク、境界、適用条件を明確にします。
- [design-agent-work-system](../../../../skills/design-agent-work-system/references/locales/ja/SKILL.md)は、仕事を支えるエージェント・ツール・情報資源・実行環境と相互作用を設計します。依頼範囲で実装・接続・検証を含めます。

両Skillは、設計と評価の対象が異なります。必要な基礎があれば独立して利用でき、対象の仕事の意味には共通の参照元を用います。

## 仕様と具体例

[エージェント作業システムの設計原則](../../../../spec/locales/ja/agent-work-system-design.md)は、責務配分、ツールのインターフェースと組合せ、情報供給、実行条件、評価、能力変化への適応を定めます。[プロセスフレームワーク](../../../../spec/locales/ja/process-framework.md)とは独立しており、フレームワークの英語・日本語本文は0.6.0から変更していません。[ALPS Specification](../../../../spec/locales/ja/ALPS-SPEC.md)が、二つの基盤をAgent Skillで統合します。

[サービス変更の例](../../../../examples/locales/ja/README.md)は、対象Skill、Python測定ツール、合成入力、適用基準、評価ケースを含みます。エージェントが証拠を解釈し、ツールが確定した検証・計算・比較を行う構成を示します。この例は、Plugin Skillの発見対象外に同梱する参照資料です。

仕様では、目的と成果の独立したセクション、活動とタスクの推奨する構造、NOTEの表記と参考情報としての役割を定めます。両設計Skillにもこの記述構造を適用しています。ツールとの対応では、実行を支える能力に加えて、実装する統制事項と強制する制約を識別し、構成による限界と仕事の要求を区別します。

評価では、記述の妥当性、ツールと接続の動作、代表的な仕事を通じた有効性を区別します。日英資産、発見用リンク、Host固有のmanifest、リポジトリテスト、検証案内を、二つの設計Skillに対応させています。

## 0.6.0からの更新

Plugin全体を更新し、クライアントを再読み込みしてください。仕様と例の資源を利用できるよう、`skills/`とともに`spec/`と`examples/`を保持します。発見されるPlugin Skillは、`design-process-description`と`design-agent-work-system`です。

既存のプロセス記述Skillのパスと中心的な責務は維持します。規範内容と配布構造の追加を含むため、[版管理方針](../versioning.md)に従うMINORリリースです。独自のファイル許可リストや発見対象リストを管理する利用者は、新Skillと付属ファイルを含める必要があります。この版での作業システム設計には、統合した仕様とその評価要求を適用します。今回の更新で、利用者の既存記述やデータを変換することはありません。
