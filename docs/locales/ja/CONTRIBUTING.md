貢献は、リポジトリのライセンスおよび[開発者原産地証明1.1](../../../DCO)に基づいて受け入れます。

## 貢献前の確認

- [LICENSE](../../../LICENSE)、[NOTICE](../../../NOTICE)、[DCO](../../../DCO)および[AGENTS.md](AGENTS.md)を確認してください。
- 変更した英語版と日本語版の対応資産は、意味を整合させてください。
- 秘密情報、または公開およびライセンス付与の権限を持たない資料を提出しないでください。
- 単一スキルという製品境界、公開動作またはライセンス境界を変更する場合は、実装前に検討してください。

## 証明と権利

貢献に含まれる各コミットには、貢献者自身の`Signed-off-by`トレーラーが必要です。次のコマンドで作成します。

```console
git commit --signoff
```

トレーラーは[DCO](../../../DCO)の各事項を証明するものであり、暗号学的な署名ではありません。他者の著者情報を保持し、DCOに基づく証明の連鎖と適用ライセンスが提出を許すことを確認してください。

第三者資料について、出典、著者、ライセンスおよび許諾を特定してください。リポジトリが利用根拠を文書化し配布できない文章、図、例、翻訳または資産を複製しないでください。引用は必要な長さに限り、正確な出典を示してください。出典表示だけで許諾が得られるわけではありません。

## 変更の準備と検証

1. トピックブランチで作業し、無関係な変更を分離します。
2. 影響する英語版と日本語版の対応資産を更新します。
3. 情報項目ごとに正本を一つにし、他のファイルから相対リンクで参照します。
4. 該当する場合は、`skills/design-process-description`の公式検証、マニフェストとホストの検査、リポジトリテスト、相対リンク検査および`git diff --check`を実行します。
5. 最終差分全体を確認します。
6. `--signoff`を付けてコミットします。

変更を提案するときは、成功した検査と実行できなかった検査を報告してください。
