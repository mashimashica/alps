# リポジトリ作業指示

[英語版](../../../AGENTS.md)

この指示はリポジトリ全体に適用します。

## 正本

- [`skills/design-process-description/SKILL.md`](../../../skills/design-process-description/SKILL.md)は、配布する唯一のスキルについて正本となる英語記述です。
- その`references/`配下にある三つの英語ファイルは、ルートスキルから条件付きで読む設計ガイダンスです。
- `skills/design-process-description/references/locales/ja/`には、対応する日本語版があります。英語を正本とし、変更した対応資産は、正規名称、パス、メタデータキー、コードリテラルおよび規範的な強さを保ちながら意味を同等にします。
- [`skills/`](../../../skills/)は配布元です。`.agents/skills/design-process-description`は、その配布元を指す相対探索シンボリックリンクに過ぎません。
- `.claude-plugin/`、`.codex-plugin/`および`.cursor-plugin/`は正本ではないホストアダプターです。追加の振る舞いを設けず、単一の配布スキルを公開します。

将来のリポジトリ要件がこの境界を明示的に変更しない限り、別の配布スキル、プロセスの意味に関する第二の正本、生成コピーまたは互換エイリアスを追加しません。

## リポジトリでの作業

- 編集前に、現在のコミット済み状態と今回の作業に属する差分全体を確認します。
- 無関係な変更と利用者による変更を保持します。
- 通常必要な指示はルートスキルに置き、読む条件を具体的に示せる場合だけ既存の三参考資料の一つへ詳細を置きます。
- 再利用可能なプロセス知識を、一回の適用、リポジトリ操作およびホスト表示メタデータから分けます。
- 英語の利用者向け正本を変更したときは日本語版も更新し、通常の文書レビューとして対応関係を確認します。
- リポジトリ内容には相対Markdownリンクを使用し、情報項目ごとに正本を一つに保ちます。

## 検証

リポジトリ変更では、該当する通常の検査を実行します。

- `skills/design-process-description`に対する公式Agent Skill検証。
- ルートAgent Pluginおよびホストアダプターの検証。
- `python3 -m unittest discover -s tests -p 'test_*.py'`。
- 相対Markdownリンク検査。
- 空白および最終差分の検査。

機械検査は形式とリポジトリ整合性を確認するものであり、プロセスの意味を追加しません。

## 提供

最終差分を確認し、成功、失敗または実行不能だった検査を報告します。利用者が明示的に依頼しない限り、リリース公開やタグ作成を行いません。
