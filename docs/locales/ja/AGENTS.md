# リポジトリ作業指示

[英語版](../../../AGENTS.md)

この指示はリポジトリ全体に適用します。`localization.yaml`は英語を正本、日本語を
対応言語として定めます。英語と日本語の対応資産を変更するときは、正規識別子、
パス、メタデータキー、コードリテラルおよび規範的な強さを変えず、意味を同等に
保ちます。

作業に選択した配布スキルまたはリポジトリ開発用スキルは、適用前に`SKILL.md`を
最後まで読みます。

## 正本となる資産

リポジトリの全資産を同等の情報源として扱わず、対象に応じて正本を判断します。

| 対象 | 正本 | 境界 |
| --- | --- | --- |
| 一般的なプロセス構成概念と意味 | [`spec/process-framework.md`](../../../spec/process-framework.md) | 上位規範です。ALPS仕様より優先します。 |
| PFのエージェントスキルへの適用 | [`spec/ALPS-SPEC.md`](../../../spec/ALPS-SPEC.md) | プロセススキル表現、発見用投影、資源、受け渡しおよび検証境界の薄いプロファイルです。 |
| 配布対象プロセススキル | [`skills/reusable-work-design/SKILL.md`](../../../skills/reusable-work-design/SKILL.md) | 再利用可能な作業設計プロセスの正本プロセス記述です。 |
| リポジトリ配置、配布境界、変更手順 | この`AGENTS.md` | 本リポジトリでの作業を統制します。 |

ホストアダプター、マニフェスト、テスト、表示資産または検証結果から、プロセスの
意味またはALPS要求事項を推論しません。

## リポジトリと配布の配置

| パス | 役割 | 配布上の位置付け |
| --- | --- | --- |
| `skills/reusable-work-design/` | `alps`プラグインが公開する一つのプロセススキルの唯一の正本。 | 配布対象です。 |
| `.agents/skills/reusable-work-design` | リポジトリ開発時の発見ビューを提供する相対シンボリックリンク。 | 配布元を指し、内容を複製しません。 |
| `.agents/skills/review-alps/` | 意味および配布境界の横断レビュー。 | リポジトリ開発専用であり、プラグインスキルとして登録しません。 |
| `.agents/skills/sync-locales/` | 英語・日本語間の意味同等性および対応範囲のレビュー。 | リポジトリ開発専用であり、プラグインスキルとして登録しません。 |
| `spec/` | プロセスフレームワークおよびALPS仕様。 | リポジトリの仕様資産です。 |
| `spec/locales/ja/`および`docs/locales/ja/` | 対応する日本語資産。 | 英語を正本とする言語資産です。 |
| `.claude-plugin/`、`.cursor-plugin/`、`.codex-plugin/` | 対応ホストの発見用または表示用メタデータ。 | アダプターであり、ALPSの意味を再定義しません。 |

`skills/`を配布スキルの唯一の正本とします。`.agents/skills/`はリポジトリ開発用の
ビューであり、全ホスト共通の規約ではありません。Agent Pluginsは配布を提供し、
適用するホストがスキルの発見、選択、有効化および実行を担います。

採用、版管理、統制された変更、廃止および統治は、再利用可能な作業設計プロセス
ではなく、リポジトリまたは組織の方針が担います。

## 変更時に使用するプロセス

| 変更対象 | 必要なプロセスまたはレビュー観点 |
| --- | --- |
| プロセスフレームワークまたはALPS仕様の意味 | `review-alps`を適用し、影響する各英語・日本語ペアに`sync-locales`を適用します。 |
| `skills/reusable-work-design/SKILL.md`またはその日本語版 | プロセス自身の自己整合性および意味上の固定点をレビューし、`review-alps`と`sync-locales`を適用します。 |
| README、AGENTS、CONTRIBUTING、版管理方針または他の対応ガイダンス | `sync-locales`および関係する`review-alps`の意味・配布境界検査を適用します。 |
| プラグインマニフェスト、ホストアダプター、OpenAIメタデータ、シンボリックリンクまたは配置 | 適用する公式形式検査、リポジトリ整合性検査および`review-alps`の配布境界レビューを適用します。 |

## 意味および製品上の不変条件

- `alps`はプラグインおよびリポジトリのブランド名です。
- `reusable-work-design`はエージェントスキルの発見用識別子です。
- 英語のプロセス名称は`Reusable Work Design Process`、日本語の対応名称は
  `再利用可能な作業設計プロセス`です。
- 配布スキルは、一つの目的を持つ一つのプロセスを表現します。その目的は、反復
  または共有されるエージェント作業を、再利用可能で評価可能なプロセススキルとして
  確立することです。
- プロセススキル表現の作成、レビューおよび改訂は境界内です。表現対象プロセスの
  実行および採用済みスキルの統治は境界外です。
- 名称、目的、成果、任意のプロセス要素、受け渡し、テーラリング、アセスメント
  およびその他の一般的な意味は、PFを正本とします。
- 任意の詳細は、発見、適用、組合せまたはアセスメントに必要な場合だけ含めます。
- 機械検査は、意味上の適合、成果達成、プロセス実行適合または自己整合性を判定
  しません。

## リポジトリでの作業手順

### 編集前

- リポジトリの状態、依頼範囲および今回の作業に属する差分全体を確認します。
- 正本、影響する意味上の層、対応言語ペア、相対参照、ホスト向け投影および配布境界を
  識別します。
- 無関係な変更および利用者による変更を維持します。
- 一つの情報項目につき正本を一つにし、利用箇所からリンクします。
- 過去のリリース文書の事実を維持します。削除によってリンクが壊れる場合は、
  リリース履歴を書き換えず、不変のタグまたはコミットへのリンクで修復します。

### 検証とレビュー

検証を次の三層に分けます。

1. Agent Skills、Agent Pluginsおよび対応ホストの公式形式検査を適用する。
2. プロセスの意味を解釈せず、リポジトリが管理するファイル、版、パス、リンク、
   シンボリックリンク、言語対応範囲および配布境界の整合性を検査する。
3. `sync-locales`の結果を含めて`review-alps`を適用し、プロセス意味論、発見用投影、
   プロセス境界、英語・日本語の意味および各層の製品説明をレビューする。

最低限、Pythonユニットテスト、JSON・YAML構文解析、Markdown相対リンク検査、
シンボリックリンク先検査、`git diff --check`、現行参照検索、対応言語資産の存在
および今回の作業に属する差分全体を確認します。

公式形式検査およびリポジトリ整合性検査の結果を、意味レビューと区別して報告します。
いずれもALPS適合、成果達成または自己整合性の自動証明として報告しません。

### 提供

最終差分を確認し、成功した検査、失敗した検査、実行できなかった検査、前提および
制限事項を記録します。利用者から依頼されない限り、コミット、ブランチ更新、公開、
プルリクエストの作成・更新またはその他の外部変更を行いません。
