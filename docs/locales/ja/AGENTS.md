# リポジトリ作業指示

[英語版](../../../AGENTS.md)

この指示はリポジトリ全体に適用します。`localization.yaml`は英語を正本、日本語を対応言語として定めます。英語と日本語の対応資産を変更するときは、正規識別子、パス、メタデータキー、コードリテラルおよび規範的な強さを変えず、意味を同等に保ちます。

作業に選択した各ALPS表現またはリポジトリ開発用スキルは、適用前に`SKILL.md`を最後まで読みます。

## 正本となる資産

リポジトリの全資産を同等の情報源として扱わず、対象に応じて正本を判断します。

| 対象 | 正本 | 境界 |
| --- | --- | --- |
| プロセス構成概念とその意味 | [`spec/process-framework.md`](../../../spec/process-framework.md) | 上位規範です。ALPS仕様と矛盾する場合はプロセスフレームワークを優先します。 |
| エージェントスキルによる表現、ライフサイクル、適合 | [`spec/ALPS-SPEC.md`](../../../spec/ALPS-SPEC.md) | 一つの物理ファイル形式を必須とせずにALPSを規定します。 |
| 配布対象の各ALPS表現 | 対応する[`skills/*/SKILL.md`](../../../skills/) | そのスキルの正本となるプロセス記述またはプロセス以外の表現です。 |
| リポジトリ配置、配布境界、エージェントの作業手順 | この`AGENTS.md` | 本リポジトリでの作業を統制します。 |
| 起草例 | [`skills/define-alps/references/SKILL-template.md`](../../../skills/define-alps/references/SKILL-template.md) | 参考用の出力作成資産であり、規範的なALPS構造を定義しません。 |

テンプレート、記録、環境への対応付け、リポジトリテスト、ホストアダプターまたは表示用資産から、ALPSの要件を推論しません。

## リポジトリと配布の配置

| パス | 役割 | 配布上の位置付け |
| --- | --- | --- |
| `skills/` | ALPSプラグインが公開する四つのエージェントスキル表現の唯一の正本。 | 配布対象です。 |
| `.agents/skills/alps-reference-model`、`.agents/skills/define-alps`、`.agents/skills/apply-alps`、`.agents/skills/manage-alps` | `.agents/skills/`を探索するリポジトリ開発用エージェントに統合探索ビューを提供する相対シンボリックリンク。 | リンク先の表現を`skills/`から配布します。ここに内容を複製しません。 |
| `.agents/skills/review-alps/` | ALPSリポジトリ変更の命題単位および横断レビュー。 | リポジトリ開発専用であり、プラグインスキルとして登録・公開しません。 |
| `.agents/skills/sync-locales/` | 英語・日本語間の意味同等性と更新範囲のレビュー。 | リポジトリ開発専用であり、プラグインスキルとして登録・公開しません。 |
| `spec/` | 正本となるプロセスフレームワークおよびALPS仕様。 | リポジトリの仕様資産です。 |
| `spec/locales/ja/`および`docs/locales/ja/` | 対応する日本語資産。 | 英語を正本とする対応言語資産です。 |
| `.claude-plugin/`、`.cursor-plugin/`、`.codex-plugin/` | ホスト固有の探索用または表示用メタデータ。 | アダプターであり、ALPSの意味を再定義してはなりません。 |

`.agents/skills/`は、すべてのホストに共通する規約として扱いません。プラグインホストは`skills/`と各ホストに対応するアダプターを通じて配布スキルを探索します。

リポジトリ開発用スキルは、配布用プラグインスキルとして登録、公開または探索されないまま、リポジトリのチェックアウトやパッケージアーカイブに通常のファイルとして含めたままにしてよいです。

新たなリポジトリ開発用スキルは、`review-alps`にも`sync-locales`にも責務が明確に収まらない反復作業が実際に生じてから追加します。

## 変更時に使用するプロセス

| 変更対象 | 必要なプロセスまたはレビュー観点 |
| --- | --- |
| プロセスフレームワークまたはALPS仕様の意味 | `review-alps`を用います。影響するすべての英語・日本語対応資産には`sync-locales`を用います。 |
| ALPS参照モデル、参照プロセスまたは他のALPS表現 | `define-alps`で表現を検証し、`review-alps`でリポジトリ変更をアセスメントします。対応資産には`sync-locales`を用います。 |
| README、AGENTS、CONTRIBUTINGまたは他の対応ガイダンス | `sync-locales`を用います。用語、リンク、正規パスを確認し、影響する意味または配布境界を`review-alps`で確認します。 |
| エージェントスキル形式、プラグインマニフェスト、ホストアダプター、シンボリックリンクまたはリポジトリ配置 | 該当する公式標準検査を適用し、`review-alps`を用いて正本と配布対象・リポジトリ専用資産の境界を確認します。 |

## 維持する意味上の条件

- エージェントスキルは既定ではプロセスを表現し、プロセス以外の表現は`metadata.alps.kind`を宣言します。
- プロセスビューは、参照する出典要素の来歴と追跡可能性を維持します。ビューに固有の内容やビュー内で変更した内容は、出典プロセスを変更せず、出典プロセスへの適合を確立しません。
- 適用する出典プロセスは管理されたテーラリングによって変更し、正本となるプロセス記述は`define-alps`による統制された再定義によって変更します。
- `skills/`を配布対象のエージェントスキル表現の唯一の正本として維持します。
- リポジトリ開発用スキルは`.agents/skills/`の実ディレクトリとして維持し、配布用プラグインスキルとして扱いません。
- 機械検査の結果は、ALPSへの適合、成果の達成可能性、成果達成またはプロセス実行適合を判定しません。

## リポジトリでの作業手順

### 編集前

- リポジトリの状態、依頼された範囲および今回の作業に属する差分全体を確認します。
- 編集前に、正本、影響する意味上の層、対応言語資産、正規参照および配布境界を特定します。
- 無関係な変更とユーザーによる変更を保持します。
- 一つの情報項目につき正本を一つにし、利用箇所から相対リンクで参照します。

### 検証とレビュー

- 上記の変更対応表で選択した各プロセスまたはリポジトリ開発用スキルを適用します。
- 検証を次の三層に分けます。
  1. エージェントスキルおよびプラグインの形式を、該当する公式標準に対して検査する。
  2. プロセスの意味を解釈せず、リポジトリが管理するファイル、版、パス、リンク、シンボリックリンクおよび配布境界の整合性を検査する。
  3. プロセスフレームワーク、ALPS仕様、参照モデル、参照プロセス、記録ならびに英語・日本語対応資産を命題単位でレビューする。
- 最低限、空白、変更した相対リンク、正規参照、英語・日本語対応資産の存在、リポジトリの配布境界および今回の作業に属する差分全体を確認します。
- 標準検査およびリポジトリ整合性検査の結果を、横断的な意味レビューおよび適合判断と区別して報告します。

### 提供

- 最終差分を確認し、実行した検査、失敗した検査および実行できなかった検査を記録します。
- ユーザーから依頼されない限り、コミット、プッシュ、公開、プルリクエストの作成・更新、その他の外部変更を行いません。
