# ALPSへの貢献

  <a href="../../CONTRIBUTING.md">英語</a> | <strong>日本語</strong>
</p>

ALPSへの貢献に関心をお寄せいただき、ありがとうございます。貢献は、リポジトリのライセンスおよび開発者原産地証明1.1（DCO）に基づいて受け入れます。

## 貢献前の確認

- [ライセンス](../../LICENSE)、[NOTICE](../../NOTICE)および[DCO](../../DCO)を確認してください。
- 変更が日英双方に影響する場合は、対応する資産間の整合性を保ってください。
- 秘密情報、または公開およびライセンス付与の権限を持たない資料を提出しないでください。
- ALPSの意味、適合要求またはライセンス境界を変更する場合は、事前にGitHub上で課題を作成してください。

## 開発者原産地証明

貢献に含まれるすべてのコミットには、貢献者自身の`Signed-off-by`トレーラーが必要です。このトレーラーは[DCO](../../DCO)の各事項を証明するものであり、暗号学的なコミット署名とは異なります。

次のコマンドでトレーラーを追加できます。

```console
git commit --signoff
```

トレーラーの氏名およびメールアドレスは、証明を行う貢献者を識別でき、当該コミットの著者情報と整合するものにしてください。他者の成果を含める場合は、その著者情報を維持し、DCOに基づく証明の連鎖と適用ライセンスが提出を許すことを確認してください。

ALPSはコントリビューターライセンス契約ではなくDCOを採用します。貢献者は自らの貢献に対する著作権を保持し、そのファイルに適用されるライセンスに基づいて貢献を提供します。

## 第三者資料

第三者資料を含める場合は、出典、著者、適用ライセンスおよび許諾を明示してください。

- 提案する利用を許可する文書をリポジトリ内に保持できない場合は、第三者による文章、図、表、例または翻訳を複製しないでください。
- 翻訳または原文に近い言い換えも、原著作物に依拠し得ます。出典との照合および分類根拠の記録なしに、独自表現として扱わないでください。
- 引用であることを明示し、必要な長さに限り、正確な出典を示してください。出典表示だけで許諾が得られるわけではありません。
- 画像、アイコンその他の資産について、作成者を示し、適用されるリポジトリライセンスで配布できることを確認してください。
- 規格、書籍、製品、組織または商標への言及によって、それらの資料がALPSのライセンス対象になることはありません。

メンテナーは、受入れ前にライセンスの証拠、書面による許諾、または提出資料の置換を求めることがあります。

## 変更の準備

1. トピックブランチで作業し、無関係な変更を分離してください。
2. 必要に応じ、対応する英語版または日本語版の資産を更新してください。
3. 情報項目ごとに正本を一つに保ち、他の文書からは相対リンクで参照してください。
4. 影響を受けるスキルパッケージが提供する検証を実行してください。
5. `git diff --check`を実行し、変更した相対リンクと最終差分を確認してください。
6. `--signoff`を付けてコミットしてください。

- [ ] 第三者の出典、許諾、引用および資産の作成者を記録した。
- [ ] 対応する英語版と日本語版を確認し、必要な更新を行った。
- [ ] 関係する検証に合格した。実行しなかった検証がある場合は、その検証と理由をプルリクエストに記載した。
