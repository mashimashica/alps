# ALPS Specification

[英語正本](../../ALPS-SPEC.md)

## 1. 適用範囲と規範上の位置付け

本仕様はプロセス記述をAgent Skillへ対応付ける。[プロセスフレームワーク](process-framework.md)は、プロセスの意味、関係、規範語、評価を定め、本仕様に優先する。

物理的な`SKILL.md`の形式は[Agent Skills形式](https://agentskills.io/specification)が定める。以下の対応付けは、プロセスを記述するSkillに適用する。

## 2. 対応付け

| Agent Skillの内容 | プロセスとしての意味 |
| --- | --- |
| frontmatterの`name` | 発見に用いるSkill識別子。 |
| frontmatterの`description` | 作業とSkillの適用場面の要約。 |
| 本文タイトル | プロセス名称。 |
| 本文の目的と成果 | 作業の目標と、観察可能な結果条件。 |
| 必要に応じた他の本文内容とリンク先資源 | フレームワークが意味を定める、作業詳細、境界要素、適用条件、参照情報。 |

本文には名称、目的、一つ以上の成果を含めなければならない。追加の要素は、必要な詳細に応じて含める。活動とタスクは、そのまとまり、寄与、規範強度が明確になる見出しと文で表せる。文書構造は、作業上の関係と実行順序の区別を維持しなければならない。

frontmatterとHost表示は、記述の意味と範囲に整合しなければならない。発見情報は記述を要約するものであり、その代わりにはならない。Skillの読込みは、その作業が実行されたことを示さない。参照資料は、プロセス記述と区別可能でなければならない。

## 3. 正本と資源

プロセス記述を記載する各Skillは、一つの識別可能な正本記述を持たなければならない。翻訳、要約、リンク先の資料は、正本との関係を明確にし、その意味と規範強度を維持しなければならない。

Skillは、必要な各付属資源の役割と利用条件を識別しなければならない。必要な参照は、意図した配布構成の下で利用可能でなければならない。パッケージ内の相対リンクは、その構成の下で解決しなければならない。外部参照は、意図した出典を識別し、アクセス条件がある場合はそれも明示しなければならない。必要な参照を確認できない場合は、フレームワークの規則を適用する。

プロセスの意味のレビューとAgent Skillの形式のレビューは区別する。後者では、適用形式、発見情報の整合性、正本の識別、必要な資源の利用可能性を確認する。

作成の支援には、[design-process-description](../../../skills/design-process-description/references/locales/ja/SKILL.md)、その[最小テンプレート](../../../skills/design-process-description/references/locales/ja/SKILL-template.md)、[具体例](../../../skills/design-process-description/references/locales/ja/examples.md)を参照する。テンプレートと具体例は参考情報である。
