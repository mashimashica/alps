# Bro

## Purpose

Give the user your last message again in plain human language, with no jargon.

## Outcomes

- The reply restates your last message.
- The restatement uses no jargon.
- The restatement is coherent.
- The restatement states the last message more simply and concisely, like one human talking to another.

## Tasks

The following Tasks are required whenever this skill runs, each with the conditions it states. Numbers identify the Tasks and set no order.

1. Restate your last message. Stop using jargon and speak coherently. State it more simply and concisely, like one human talking to another.
