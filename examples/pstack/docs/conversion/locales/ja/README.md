# ALPS形式のpstack

[英語版](../../README.md)

このディレクトリツリーは、pstack PluginをALPS形式へ変換した非公式のものである。ALPSの二つの設計Skillの参照資料であり、pstackの作者と提携しておらず、その承認も受けていない。

## 変換元

| 項目 | 値 |

| Plugin | pstack 0.15.44 |
| リポジトリ | `https://github.com/cursor/plugins`、パス`pstack/` |

| ライセンス | MIT、Copyright (c) 2026 Lauren Tan。[LICENSE](../../../../LICENSE)を参照。 |

このツリーをALPSリポジトリへ追加する最初のコミット群は、上流のファイルを無変更で保持する。そのため変換は、上流のバイト列に対する差分として読める。

## 状況

変換は進行中である。

- 完了：すべてのSkill本文、poteto-modeのすべてのプレイブック、レビューを行うエージェントの定義を、導出した目的と導出した成果を持つプロセス記述として書き直した。同梱する四つのツールにはツール利用の参照文書がある。frontmatter、スクリプト、データファイル、ワーカー規則、起動用エージェントの定義、Claude Codeアダプターは上流から変更していない。
- 進行中：変換した各ファイルに対する、独立した忠実性レビューとフレームワーク適合レビュー、およびそれらが求める修正。
- 未実施：記録した変換元への指摘の検証、代表的な仕事での試行、ファイル別の記録を含む完全なガイド。

目的と成果は変換が導出したものである。上流の作者が書いたものではなく、作者の確認も受けていない。レビューと試行が完了するまで、このツリーを上流のpstackと同等のものとして扱わない。
