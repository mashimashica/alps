# ALPS 0.2.0

ALPS 0.2.0 adopts Agent Plugins 1.0 as the repository's portable package binding and shortens the three ALPS Reference Model Skill identifiers.

## Package layout

The repository root is now the Agent Plugin root:

```text
alps/
├── plugin.json
├── skills/
│   ├── define-alps/
│   ├── apply-alps/
│   └── manage-alps/
├── .alps/
│   ├── localization.yaml
│   └── spec/
└── ...
```

The root `plugin.json` declares conformance to the Agent Plugins 1.0 manifest schema. ALPS 0.2.0 provides portable Agent Skills only; no root `mcp.json` is included in this release.

ALPS must be installed as the complete Plugin Package. The shared normative assets under `.alps/` are part of the Package and remain at a stable location relative to `skills/`; copying only the Skill directories does not preserve the required references.

## Skill identifier migration

| ALPS Process | Previous identifier | New identifier |
| --- | --- | --- |
| Definition Process | `define-agent-lifecycle-process-skills` | `define-alps` |
| Application Process | `apply-agent-lifecycle-process-skills` | `apply-alps` |
| Management Process | `manage-agent-lifecycle-process-skills` | `manage-alps` |

The directory paths move at the same time:

| Previous path | New path |
| --- | --- |
| `.agents/skills/define-agent-lifecycle-process-skills/` | `skills/define-alps/` |
| `.agents/skills/apply-agent-lifecycle-process-skills/` | `skills/apply-alps/` |
| `.agents/skills/manage-agent-lifecycle-process-skills/` | `skills/manage-alps/` |
| `.agents/localization.yaml` | `.alps/localization.yaml` |

Consumers must update stored paths, discovery records, invocations, automation, and references. The former paths and identifiers are not retained as duplicate aliases because each Skill Package has one authoritative location and identifier.

## Compatibility status

ALPS remains in initial development. This release changes repository path contracts and machine-consumed Skill identifiers, so it is a MINOR release under the pre-1.0 versioning rules. Pin the Git tag and commit SHA when synchronizing or installing ALPS assets.
