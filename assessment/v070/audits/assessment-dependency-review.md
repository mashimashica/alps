# Conditional dependency review: no qualifying B after round three

This review addresses the contingency that the final ordinary development round supplies no qualifying B. It does not grade B3, infer pending results, or decide source attribution. Its sole sources are `protocol.md`, `gates.md`, `development-round-3.md`, `RESUME.md`, and `progress.md`.

The immediate consequence is a blocked candidate-dependent comparison, not cancellation of all assessment work. Preserve frozen A and all candidate evidence. Finish the prescribed round-three evidence, independent judgments, and closeout before determining whether the contingency applies. Progression qualification permits entry to main; only the subsequent full acceptance routes can justify accepting a core change. Failure to qualify is therefore distinct from an inconclusive completed main comparison.

The controlling instructions are explicit: select one immutable qualifying B before main A/B; do not run `prepare_main.py` before documenting that selection; allow at most three ordinary development rounds; retain every required base stage; and stop the dependency when further required work exceeds the permitted rounds or budget. Four remaining reserve slots are not permission for a fourth round, a new exploratory baseline campaign, or relabeling generated defects as infrastructure failures.

These blocks follow the existing candidate and stage-order requirements, rather than new performance gates. The instruction that example and release assessment can still yield useful findings does not erase their final selection and package dependencies. Similarly, preserving A determines the retained core; it does not create a second comparison arm or authorize a substituted A-versus-A experiment. Neither descriptive C results nor development results can satisfy the main effectiveness or burden routes.

Useful work should continue while the blocked dependencies are made reviewable. Complete evidence recovery, independent grades, adjudications, fidelity checks, attempt accounting, and causal-attribution limitations for already prescribed work. Preserve original artifacts and hashes; reconcile ledgers, pending slots, and resumable dependencies. Existing A and C evidence can support baseline findings, component examination, readability review, and provisional exemplar eligibility assessment. A package generated under a rejected core proposal is not automatically disqualified as an exemplar; apply the existing artifact eligibility criteria independently. Final selection still awaits the declared sequence or an explicit scope amendment.

The original C control allocation offers substantial fresh work without inventing a replacement experiment. Freeze its schedule and inputs before execution; retain common assistance, fresh contexts, independent oracles, and delayed consumer-input materialization. Record C outputs as C-control evidence and keep the A/B stages blocked. Do not use these results to restart ordinary candidate tuning. Baseline mechanical, distribution, locale, and Host preparation can also expose useful facts, but preliminary checks cannot certify an unfrozen final package. Count any fresh creator/consumer task honestly; calling it a Host check does not exempt it from the budgets.

The concrete decision needed is how to disposition the unsatisfied A/B dependency. One option is an explicit amendment extending candidate development, stating the additional rounds, task allowance, candidate qualification procedure, and fresh confirmation required before the retained base comparison can proceed. This review does not recommend an unauthorized fourth round. The alternative is an explicit amendment retaining A and defining the deliverables, stage changes, denominators, ordering, and limitations of a baseline/control/example/release assessment. That alternative must identify every omitted or altered A/B-dependent stage; it cannot be labeled completion of the original program.

Recommended handling: close H03 faithfully, preserve A, checkpoint the concrete dependency record durably, and continue independent authorized work, especially the unchanged C control and evidence preparation. Present the actual failed qualification requirements, remaining planned work, and counted reserve alongside the scope decision. Keep blocked stages visible and resumable. This preserves useful progress while leaving changes to the approved experiment explicit; it establishes neither convergence nor release readiness.
