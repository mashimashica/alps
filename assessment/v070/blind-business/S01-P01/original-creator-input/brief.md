# Brief: select a response-time value

Create an Agent Skill for this work: given a non-empty finite list of integer response times in milliseconds, identify the smallest listed value. Repeated occurrences do not change the result. The result must be a value present in the supplied list and no listed value may be smaller. The task concerns the supplied numbers, not whether their measurements represent real service quality. Input collection and measurement are outside this work.

The user wants a usable description of this small piece of work. Choose the amount of detail the work needs; there is no required algorithm, tool, fixed report or presentation beyond ordinary Agent Skill format. Do not execute a particular business instance now. Produce a self-contained Skill folder for another agent to use later.
